## 1. テーマ一覧（`python scripts/themes.py list`）
| テーマ | 配色 | 印象 | 向いている場面 |
|---|---|---|---|
| `swiss` | 白×黒×赤 | 端正・ビジネス | 社外提案・役員報告・顧客向け（**最も無難**） |
| `washi` | 和紙×墨×朱 | 知的・編集的 | 講演・勉強会・読み物系 |
| `blueprint` | 方眼×コバルト | 精密・技術 | 設計レビュー・アーキテクチャ・製造業 |
| `signal` | 濃紺×琥珀 | 自信・キーノート | 製品発表・経営報告・登壇 |
| `forest` | 深緑×生成り×錆 | 穏やか・信頼 | 年次報告・振り返り・方針 |
| `terminal` | 黒×蛍光緑 | 開発者・ハッカー | 技術 LT・AI/ツール紹介・コード解説 |
| `pop` | クリーム×原色ブロック | 楽しい・親しみ | 地域・自治会・子ども向け・ワークショップ |

気分マップ:
- 格調・安心 → swiss, forest ／ 知的 → washi, blueprint ／ 高揚・自信 → signal ／ 遊び・親しみ → pop, terminal
- 迷ったら「会場の明るさ」: 明るい会議室・印刷配布 → ライト系（swiss/washi/blueprint/pop）、暗いホール・登壇 → ダーク系（signal/forest/terminal）

## 2. 見せて選ばせる（Show, don't tell）
人は好みを言葉で説明できないが、見れば選べる。ユーザーがテーマを指定していないときは:
```bash
python scripts/themes.py preview --title "<本当のタイトル>" --subtitle "<本当のサブタイトル>" \
  --points "<本当の要点1>,<要点2>,<要点3>" --themes swiss,blueprint,signal --out previews/
```
- 候補は **3 つ**: 安全枠 1（swiss か washi）＋用途に合う 1 ＋意外性のある 1。
- **ユーザー自身の言葉**でプレビューする。「Option A」「サンプル」「preview」などの工程用語をスライドに載せない。
- `previews/gallery.png` を見せて選んでもらう（画像を表示できない環境では各 previews/*.html を開いてもらう）。各テーマの表紙は `previews/<theme>.png` にも保存される（「同じ原稿を N テーマで」のスライドに使える）。
- 選ばれなかったプレビューは納品前に削除する。

## 3. AI slop を避けるルール
- 紫グラデーション on 白、Inter/Roboto/Arial、中央寄せの箇条書き、角丸カードの羅列 → 使わない。テーマが既に避けている。
- 全スライド同じ形にしない。stats / statement / compare / flow を混ぜてリズムを作る（outline.py が 3 連続箇条書きを警告）。
- 強調は 1 スライド 1 か所（`hl`, `accent`, `mark`）。全部強調＝何も強調していない。
- 絵文字アイコンの多用、意味のない装飾イラスト、ストック写真風の「握手」画像は使わない。
- 余白を埋めるために要素を足さない。余白は高級感。
- スライド上に工程・メタ情報（「ここに図」「TODO」「Generated by」「スタイル案」）を残さない。

## 4. 日本語タイポグラフィ（runtime が自動適用している分と、書き手が守る分）
自動: 見出しに `word-break: auto-phrase`（文節で改行、Chrome 119+）、`text-wrap: balance`、`line-break: strict`（禁則）、見出しの `palt`（字詰め）。

書き手が守ること:
- 見出しは 2 行まで。改行位置を明示したいときは `<br>`、文節の途中で切られたくない語は `<span style="white-space:nowrap">`。
- **泣き別れ**（最終行が 1〜2 文字）を作らない。check.py が `widow` で警告 → 言い換えるか `<br>` で調整。
- 英数字は半角、前後に半角スペース（例: 「AI で 3 倍」）。全角英数字は使わない。
- 日本語にイタリックは使わない（斜体フォントが無く、機械的な斜体になる）。
- 長音「ー」や約物の連続（！？）は見出しで控えめに。
- 本文は 1 行 30 字前後が読みやすい。`.lede` は最大幅 32em で自動調整済み。

## 5. 色と余白
- テキストのコントラストは 4.5:1 以上（大きな見出しは 3:1）。check.py が計測する。
- アクセント色は面積 10% 以内。背景・線は `--accent`、文字は `--accent-ink`（テーマが読みやすい濃さを定義）。
- 余白の階層: 見出しと本文の間 > 本文ブロック間 > ブロック内。`--gap` (48px) を基準に。
- 端から 80px 以内に文字を置かない（プロジェクターで欠ける）。

## 6. 画像・図
- 画像は意味があるときだけ（実物・画面・人・場所）。雰囲気写真で余白を埋めない。
- スクリーンショットは `.frame` で囲み、必要なら一部だけ切り出して拡大。
- 図解は HTML/CSS（flow, timeline）かインライン SVG で描く。ラスター画像の図は解像度と配色がテーマと合わない。
- グラフは「直接ラベル・強調 1 本・目盛り最小限」。複雑なら dataviz の原則に従い SVG で。

## 7. 独自テーマ／ブランド対応
**軽い調整**（色だけ変える）: deck-config の `"tokens"`:
```json
"tokens": { "--accent": "#0B6E4F", "--accent-ink": "#08563D", "--inv-accent": "#7DDBB8" }
```
**新規テーマ**: 既存テーマ（例 `assets/themes/swiss.css`）をコピーして編集し、deck-config の `"theme"` にパスを書く。必須:
- 先頭コメントに `@theme @name @scheme @mood @best @font` を書く（`@font 名前 | 400,700` / 可変フォントは `400..900`）。build が Google Fonts リンクやオフライン埋め込みに使う。
- `:root` に全トークン: `--bg --fg --muted --accent --accent-ink --accent-2 --surface --surface-2 --line --on-accent --letterbox`、反転用 `--inv-bg --inv-fg --inv-muted --inv-surface --inv-surface-2 --inv-line --inv-accent`、フォント `--font-head --font-body --font-num --font-mono`、`--w-head --lh-head --radius`。
- 署名的な装飾は `.slide::before`（背景）に 1 つだけ。
- 作ったら `themes.py preview` と、`assets/examples/sample.src.html` を `--theme` で当てて `check.py` を 0 エラーにする（全レイアウトのコントラストが検証される）。
- 企業ロゴ・ブランド名はユーザーが提供したものだけを使う。
